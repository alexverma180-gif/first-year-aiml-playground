# Performance Benchmark Summary (Updated: 2026-03-21)

## Environment
- Python 3.12.13
- NumPy 2.4.3
- scikit-learn 1.8.0
- pytest-benchmark 5.2.3
- OS: Linux (Sandbox Environment)

## Core Application Functions (Iris Dataset)
| Function | Mean Time (Current) | Previous Baseline | Description |
|---|---|---|---|
| `load_data` | ~1.69 ms | ~1.56 ms | Loading and cleaning Iris dataset |
| `train_model` (KNN) | ~2.08 ms | ~1.78 ms | Training scikit-learn KNN (k=5) |
| `predict_model` | ~3.10 ms | ~2.68 ms | Prediction on test set |

## Linear Regression GD (Custom Implementation)
The implementation uses analytical gradients to reduce per-iteration complexity from O(N*D) to O(D^2).

### Baseline Performance (N=10000, D=3, 1000 epochs)
- **Training (fit)**: ~9.23 ms (Previously ~7.53 ms)
- **Prediction**: ~35.1 us (Previously ~46.2 us)

### Scaling with Number of Samples (N) [D=10, 100 epochs]
| N | Mean Time (Current) | Previous Baseline |
|---|---|---|
| 1,000 | 1.14 ms | 0.92 ms |
| 10,000 | 1.59 ms | 1.48 ms |
| 100,000 | 6.47 ms | 6.46 ms |

### Scaling with Number of Features (D) [N=10000, 100 epochs]
| D | Mean Time (Current) | Previous Baseline |
|---|---|---|
| 5 | 1.25 ms | 1.21 ms |
| 50 | 2.84 ms | 3.01 ms |
| 500 | 54.36 ms | 47.69 ms |

## Optimized vs Naive Comparison (1000 epochs)
| Setup | Naive GD Time | Optimized GD Time | Speedup |
|---|---|---|---|
| N=10k, D=10 | 162.2 ms | 7.6 ms | ~21.3x |
| N=100k, D=10 | 1012.7 ms | 12.3 ms | ~82.1x |
| N=10k, D=500 | 2375.7 ms | 141.9 ms | ~16.7x |

## Memory Analysis (Peak Memory Delta)
- Optimized GD uses more memory for high-dimensional data (D=500) due to precomputing the $D \times D$ matrix $X^TX$.
- For $N=10,000, D=500$, the optimized version showed a peak memory delta of ~4.75 MB compared to the naive version.

## Conclusions
- Performance is generally consistent with the previous baseline, with some slight variations likely due to system load or minor environment differences.
- The analytical gradient optimization remains extremely effective, providing up to ~82x speedup for large datasets (N=100,000).
- Memory overhead for $X^TX$ is stable at ~4.75 MB for D=500.
