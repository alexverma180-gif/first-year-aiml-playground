# Performance Benchmark Summary

## Environment
- Python 3.12.12
- NumPy 2.4.2
- scikit-learn 1.8.0
- pytest-benchmark 5.2.3

## Core Application Functions (Iris Dataset)
| Function | Mean Time | Description |
|---|---|---|
| `load_data` | ~1.5 ms | Loading and cleaning Iris dataset |
| `train_model` (KNN) | ~1.8 ms | Training scikit-learn KNN (k=5) |
| `predict_model` | ~2.6 ms | Prediction on test set |

## Linear Regression GD (Custom Implementation)
The implementation uses analytical gradients to reduce per-iteration complexity from O(N*D) to O(D^2).

### Baseline Performance (N=10000, D=3, 1000 epochs)
- **Training (fit)**: ~7.4 ms
- **Prediction**: ~37 us

### Optimization Impact (Naive vs. Optimized) [500 epochs]
| Dataset Size (N, D) | Naive Time | Optimized Time | Speedup |
|---|---|---|---|
| N=1,000, D=10 | 13.5 ms | 3.6 ms | ~3.8x |
| N=10,000, D=10 | 69.3 ms | 4.1 ms | ~16.7x |
| N=100,000, D=10 | 395.2 ms | 8.3 ms | ~47.5x |

### Scaling and Memory Usage [N=10000, 500 epochs]
| D | Optimized Time | Peak Memory |
|---|---|---|
| 10 | 4.0 ms | ~45 MB |
| 100 | 7.3 ms | ~45 MB |
| 500 | 83.8 ms | ~84 MB |

*Observations:*
- **Scaling with N:** Training time increases slowly with N due to the initial $O(N \cdot D^2)$ precomputation. However, the speedup over the naive $O(N \cdot D)$ per-iteration approach increases dramatically as N grows.
- **Scaling with D:** Performance scales quadratically with D ($O(D^2)$), as expected from matrix-vector multiplications in the training loop.
- **Memory Usage:** Memory usage remains stable for moderate D but increases as the precomputed $X^T X$ matrix ($D \times D$) and the input matrix $X$ ($N \times D$) grow in size.

## Conclusions
- The scikit-learn components for the Iris app are highly efficient.
- The custom `LinearRegressionGD` is highly optimized for datasets where N >> D. The analytical gradient approach provides a speedup of up to 47x for 100,000 samples compared to a naive implementation.
- Precomputation is the most efficient strategy for large-scale linear regression with Gradient Descent when the number of features is manageable (up to $D \approx 500$ in this environment).
