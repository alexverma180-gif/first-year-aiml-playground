# Performance Benchmark Summary (Updated: 2025-03-05)

## Environment
- Python 3.12.12
- NumPy 2.4.2
- scikit-learn 1.8.0
- pytest-benchmark 5.2.3
- OS: Linux (Sandbox Environment)

## Core Application Functions (Iris Dataset)
| Function | Mean Time (Current) | Previous Baseline | Description |
|---|---|---|---|
| `load_data` | ~1.56 ms | ~3.10 ms | Loading and cleaning Iris dataset |
| `train_model` (KNN) | ~2.04 ms | ~2.77 ms | Training scikit-learn KNN (k=5) |
| `predict_model` | ~2.79 ms | ~3.64 ms | Prediction on test set |

## Linear Regression GD (Custom Implementation)
The implementation uses analytical gradients to reduce per-iteration complexity from O(N*D) to O(D^2).

### Baseline Performance (N=10000, D=3, 1000 epochs)
- **Training (fit)**: ~7.56 ms (Previously ~9.71 ms)
- **Prediction**: ~40.9 us (Previously ~108 us)

### Scaling with Number of Samples (N) [D=10, 100 epochs]
| N | Mean Time (Current) | Previous Baseline |
|---|---|---|
| 1,000 | 826 us | 1.18 ms |
| 10,000 | 1.39 ms | 1.74 ms |
| 100,000 | 6.59 ms | 7.44 ms |

### Scaling with Number of Features (D) [N=10000, 100 epochs]
| D | Mean Time (Current) | Previous Baseline |
|---|---|---|
| 5 | 1.14 ms | 1.32 ms |
| 50 | 2.88 ms | 3.01 ms |
| 500 | 47.70 ms | 62.51 ms |

## Optimized vs Naive Comparison (1000 epochs)
| Setup | Naive GD Time | Optimized GD Time | Speedup |
|---|---|---|---|
| N=10k, D=10 | 158.2 ms | 7.8 ms | ~20.3x |
| N=100k, D=10 | 844.9 ms | 13.0 ms | ~65.0x |
| N=10k, D=500 | 2687.4 ms | 135.7 ms | ~19.8x |

## Memory Analysis (Peak Memory Delta)
- Optimized GD uses more memory for high-dimensional data (D=500) due to precomputing the $D \times D$ matrix $X^TX$.
- For $N=10,000, D=500$, the optimized version showed a peak memory delta of ~4.75 MB compared to the naive version.

## Conclusions
- Results are consistent with previous benchmarks, showing improved performance across all metrics in this environment.
- The analytical gradient optimization remains highly effective, providing up to 65x speedup for large datasets.
- Memory overhead for $X^TX$ is manageable up to $D=500$ but should be monitored for extremely high-dimensional datasets.
