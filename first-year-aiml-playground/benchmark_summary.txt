# Performance Benchmark Summary (Updated: 2026-03-20)

## Environment
- Python 3.12.13
- NumPy 2.4.3
- scikit-learn 1.8.0
- pytest-benchmark 5.2.3
- OS: Linux (Sandbox Environment)

## Core Application Functions (Iris Dataset)
| Function | Mean Time (Current) | Previous Baseline | Description |
|---|---|---|---|
| `load_data` | ~3.63 ms | ~1.56 ms | Loading and cleaning Iris dataset |
| `train_model` (KNN) | ~2.37 ms | ~1.78 ms | Training scikit-learn KNN (k=5) |
| `predict_model` | ~2.63 ms | ~2.68 ms | Prediction on test set |

## Linear Regression GD (Custom Implementation)
The implementation uses analytical gradients to reduce per-iteration complexity from O(N*D) to O(D^2).

### Baseline Performance (N=10000, D=3, 1000 epochs)
- **Training (fit)**: ~7.06 ms (Previously ~7.53 ms)
- **Prediction**: ~112.16 us (Previously ~46.2 us)

### Scaling with Number of Samples (N) [D=10, 100 epochs]
| N | Mean Time (Current) | Previous Baseline |
|---|---|---|
| 1,000 | 1.04 ms | 0.92 ms |
| 10,000 | 1.43 ms | 1.48 ms |
| 100,000 | 6.30 ms | 6.46 ms |

### Scaling with Number of Features (D) [N=10000, 100 epochs]
| D | Mean Time (Current) | Previous Baseline |
|---|---|---|
| 5 | 1.22 ms | 1.21 ms |

## Optimized vs Naive Comparison (1000 epochs)
| Setup | Naive GD Time | Optimized GD Time | Speedup |
|---|---|---|---|
| N=10k, D=10 | 197.5 ms | 11.7 ms | ~16.9x |
| N=100k, D=10 | 1008.4 ms | 12.0 ms | ~84.1x |
| N=10k, D=500 | 3182.7 ms | 128.9 ms | ~24.7x |

## Memory Analysis (Peak Memory Delta)
- Optimized GD uses more memory for high-dimensional data (D=500) due to precomputing the $D \times D$ matrix $X^TX$.
- For $N=10,000, D=500$, the optimized version showed a peak memory delta of ~5.00 MB compared to the naive version.

## Conclusions
- Results show performance variations compared to the previous baseline recorded on 2026-03-06.
- The analytical gradient optimization remains highly effective, providing up to ~84x speedup for large datasets (N=100,000).
- Memory overhead for $X^TX$ is consistent with previous measurements (~5.00 MB for D=500).
