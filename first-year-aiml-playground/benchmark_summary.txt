# Performance Benchmark Summary (Updated: 2026-03-10)

## Environment
- Python 3.12.13
- NumPy 2.4.3
- scikit-learn 1.8.0
- pytest-benchmark 5.2.3
- OS: Linux (Sandbox Environment)

## Core Application Functions (Iris Dataset)
| Function | Mean Time (Current) | Previous Baseline | Description |
|---|---|---|---|
| `load_data` | ~1.63 ms | ~1.56 ms | Loading and cleaning Iris dataset |
| `train_model` (KNN) | ~1.81 ms | ~1.78 ms | Training scikit-learn KNN (k=5) |
| `predict_model` | ~2.68 ms | ~2.68 ms | Prediction on test set |

## Linear Regression GD (Custom Implementation)
The implementation uses analytical gradients to reduce per-iteration complexity from O(N*D) to O(D^2).

### Baseline Performance (N=10000, D=3, 1000 epochs)
- **Training (fit)**: ~7.64 ms (Previously ~7.53 ms)
- **Prediction**: ~114.7 us (Previously ~46.2 us) *Note: Mean skewed by outliers; Median is ~24.4 us.*

| 100,000 | 6.62 ms | 6.46 ms |

## Optimized vs Naive Comparison (1000 epochs)
| Setup | Naive GD Time | Optimized GD Time | Speedup |
|---|---|---|---|
| N=10k, D=10 | 163.2 ms | 9.0 ms | ~18.1x |
| N=100k, D=10 | 1047.4 ms | 12.1 ms | ~86.5x |
| N=10k, D=500 | 2619.0 ms | 137.6 ms | ~19.0x |

## Memory Analysis (Peak Memory Delta)
- Optimized GD uses more memory for high-dimensional data (D=500) due to precomputing the $D \times D$ matrix $X^TX$.
- For $N=10,000, D=500$, the optimized version showed a peak memory delta of ~4.88 MB compared to the naive version.

## Conclusions
- Results are consistent with previous benchmarks, maintaining high efficiency in the analytical gradient optimization.
- The optimized version continues to provide significant speedups, especially for larger datasets (up to ~86x for N=100,000).
- Memory overhead for $X^TX$ remains stable at ~4.88 MB for D=500.
