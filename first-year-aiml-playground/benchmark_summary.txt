# Performance Benchmark Summary

## Environment
- Python 3.12.12
- NumPy 2.4.2
- scikit-learn 1.8.0
- pytest-benchmark 5.2.3

## Core Application Functions (Iris Dataset)
| Function | Mean Time | Description |
|---|---|---|
| `load_data` | ~1.5 ms | Loading and cleaning Iris dataset |
| `train_model` (KNN) | ~1.8 ms | Training scikit-learn KNN (k=5) |
| `predict_model` | ~2.6 ms | Prediction on test set |

## Linear Regression GD (Custom Implementation)
The implementation uses analytical gradients to reduce per-iteration complexity from O(N*D) to O(D^2).

### Baseline Performance (N=10000, D=3, 1000 epochs)
- **Training (fit)**: ~7.4 ms
- **Prediction**: ~97 us

### Comparison: Naive vs. Optimized (1000 epochs)
| Scenario | Naive Time | Optimized Time | Speedup |
|---|---|---|---|
| N=1,000, D=10 | ~27 ms | ~7.4 ms | ~3.6x |
| N=10,000, D=10 | ~147 ms | ~7.8 ms | ~18.9x |
| N=100,000, D=10 | ~868 ms | ~12.3 ms | ~70.8x |
| N=10,000, D=500 | ~2.7 s | ~141 ms | ~19.1x |

### Scaling with Number of Samples (N) [D=10, 100 epochs]
| N | Mean Time |
|---|---|
| 1,000 | 876 us |
| 10,000 | 1.35 ms |
| 100,000 | 6.17 ms |
*Observation: Training time increases with N primarily due to the initial O(N*D^2) precomputation of XTX and XTy. The per-iteration cost remains constant.*

### Scaling with Number of Features (D) [N=10000, 100 epochs]
| D | Mean Time |
|---|---|
| 5 | 1.11 ms |
| 50 | 2.41 ms |
| 500 | 43.39 ms |
*Observation: Performance scales quadratically with D, matching the O(D^2) complexity of matrix-vector multiplications in the training loop.*

## Conclusions
- The scikit-learn components for the Iris app are highly efficient.
- The custom `LinearRegressionGD` is optimized for large N by precomputing necessary matrices, making it suitable for datasets where the number of samples significantly exceeds the number of features.
- Precomputation dominates for very large datasets, but NumPy's optimized BLAS routines keep this efficient up to D=500.
