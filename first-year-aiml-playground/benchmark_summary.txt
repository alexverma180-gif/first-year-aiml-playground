# Performance Benchmark Summary (Updated: 2025-03-01)

## Environment
- Python 3.12.12
- NumPy 2.4.2
- scikit-learn 1.8.0
- pytest-benchmark 5.2.3
- OS: Linux (Sandbox Environment)

## Core Application Functions (Iris Dataset)
| Function | Mean Time (Current) | Previous Baseline | Description |
|---|---|---|---|
| `load_data` | ~1.52 ms | ~3.10 ms | Loading and cleaning Iris dataset |
| `train_model` (KNN) | ~1.77 ms | ~2.77 ms | Training scikit-learn KNN (k=5) |
| `predict_model` | ~2.48 ms | ~3.64 ms | Prediction on test set |

## Linear Regression GD (Custom Implementation)
The implementation uses analytical gradients to reduce per-iteration complexity from O(N*D) to O(D^2).

### Baseline Performance (N=10000, D=3, 1000 epochs)
- **Training (fit)**: ~7.45 ms (Previously ~9.71 ms)
- **Prediction**: ~41.8 us (Previously ~108 us)

### Scaling with Number of Samples (N) [D=10, 100 epochs]
| N | Mean Time (Current) | Previous Baseline |
|---|---|---|
| 1,000 | 900 us | 1.18 ms |
| 10,000 | 1.44 ms | 1.74 ms |
| 100,000 | 6.15 ms | 7.44 ms |

### Scaling with Number of Features (D) [N=10000, 100 epochs]
| D | Mean Time (Current) | Previous Baseline |
|---|---|---|
| 5 | 1.19 ms | 1.32 ms |
| 50 | 2.69 ms | 3.01 ms |
| 500 | 47.16 ms | 62.51 ms |

## Optimized vs Naive Comparison (1000 epochs)
| Setup | Naive GD Time | Optimized GD Time | Speedup |
|---|---|---|---|
| N=10k, D=10 | 157.1 ms | 7.6 ms | ~20.6x |
| N=100k, D=10 | 845.0 ms | 12.8 ms | ~66.0x |
| N=10k, D=500 | 2239.0 ms | 142.8 ms | ~15.7x |

## Memory Analysis (Peak Memory Delta)
- Optimized GD uses more memory for high-dimensional data (D=500) due to precomputing the $D \times D$ matrix $X^TX$.
- For $N=10,000, D=500$, the optimized version showed a peak memory delta of ~4.75 MB compared to the naive version.

## Conclusions
- Results show significant performance improvements across all benchmarks compared to the February 2025 results.
- The analytical gradient optimization remains highly effective, providing up to 66x speedup for large datasets.
- Memory overhead for $X^TX$ is manageable up to $D=500$ and consistent with previous observations.
