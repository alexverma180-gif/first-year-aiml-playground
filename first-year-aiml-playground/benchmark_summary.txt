# Performance Benchmark Summary

## Environment
- Python 3.12.12
- NumPy 2.4.2
- scikit-learn 1.8.0
- pytest-benchmark 5.2.3

## Core Application Functions (Iris Dataset)
| Function | Mean Time | Description |
|---|---|---|
| `load_data` | ~1.5 ms | Loading and cleaning Iris dataset |
| `train_model` (KNN) | ~1.8 ms | Training scikit-learn KNN (k=5) |
| `predict_model` | ~2.5 ms | Prediction on test set |

## Linear Regression GD (Custom Implementation)
The implementation uses analytical gradients and an **Augmented Matrix** approach to reduce per-iteration complexity to $O(D^2)$ and minimize Python loop overhead.

### Baseline Performance (N=10000, D=3, 1000 epochs)
- **Training (fit)**: ~3.4 ms (Optimized with Augmented Matrix)
- **Prediction**: ~41 us

### Scaling with Number of Samples (N) [D=10, 100 epochs]
| N | Mean Time |
|---|---|
| 1,000 | 418 us |
| 10,000 | 928 us |
| 100,000 | 5.38 ms |
*Observation: Training time increases with N primarily due to the initial O(N*D^2) precomputation of the augmented covariance matrix. The per-iteration cost remains constant.*

### Scaling with Number of Features (D) [N=10000, 100 epochs]
| D | Mean Time |
|---|---|
| 5 | 714 us |
| 50 | 2.02 ms |
| 500 | 44.43 ms |
*Observation: Performance scales quadratically with D. The augmented matrix approach significantly reduces overhead for smaller D.*

## Conclusions
- The scikit-learn components for the Iris app are highly efficient.
- The custom `LinearRegressionGD` is highly optimized using analytical gradients and augmented matrix operations, achieving ~2-3x speedup over the previous analytical implementation and making it extremely efficient for datasets where N >> D.
- Precomputation dominates for very large datasets (N=100,000), but NumPy's optimized BLAS routines keep this efficient.
