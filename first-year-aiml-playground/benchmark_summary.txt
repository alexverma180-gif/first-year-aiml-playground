# Performance Benchmark Summary (Updated: 2026-03-03)

## Environment
- Python 3.12.12
- NumPy 2.4.2
- scikit-learn 1.8.0
- pytest-benchmark 5.2.3
- OS: Linux (Sandbox Environment)

## Core Application Functions (Iris Dataset)
| Function | Mean Time (Current) | Previous Baseline | Description |
|---|---|---|---|
| `load_data` | ~1.69 ms | ~3.10 ms | Loading and cleaning Iris dataset |
| `train_model` (KNN) | ~2.10 ms | ~2.77 ms | Training scikit-learn KNN (k=5) |
| `predict_model` | ~2.82 ms | ~3.64 ms | Prediction on test set |

## Linear Regression GD (Custom Implementation)
The implementation uses analytical gradients to reduce per-iteration complexity from O(N*D) to O(D^2).

### Baseline Performance (N=10000, D=3, 1000 epochs)
- **Training (fit)**: ~8.13 ms (Previously ~9.71 ms)
- **Prediction**: ~135 us (Previously ~108 us)

### Scaling with Number of Samples (N) [D=10, 100 epochs]
| N | Mean Time (Current) | Previous Baseline |
|---|---|---|
| 1,000 | 1.02 ms | 1.18 ms |
| 10,000 | 1.56 ms | 1.74 ms |
| 100,000 | 6.91 ms | 7.44 ms |

### Scaling with Number of Features (D) [N=10000, 100 epochs]
| D | Mean Time (Current) | Previous Baseline |
|---|---|---|
| 5 | 1.23 ms | 1.32 ms |
| 50 | 2.91 ms | 3.01 ms |
| 500 | 51.44 ms | 62.51 ms |

## Optimized vs Naive Comparison (1000 epochs)
| Setup | Naive GD Time | Optimized GD Time | Speedup |
|---|---|---|---|
| N=10k, D=10 | 176.7 ms | 8.9 ms | ~19.8x |
| N=100k, D=10 | 989.9 ms | 13.0 ms | ~75.9x |
| N=10k, D=500 | 2538.2 ms | 145.1 ms | ~17.5x |

## Memory Analysis (Peak Memory Delta)
- Optimized GD uses more memory for high-dimensional data (D=500) due to precomputing the $D \times D$ matrix $X^TX$.
- For $N=10,000, D=500$, the optimized version showed a peak memory delta of ~4.88 MB compared to the naive version.

## Conclusions
- Results indicate a slight performance improvement compared to the previous benchmarks, potentially due to runtime variations in the sandbox environment.
- The analytical gradient optimization continues to provide substantial speedups, especially for large datasets (N=100,000), reaching ~75.9x.
- Memory overhead for $X^TX$ remains within expected bounds (~4.88 MB for D=500).
